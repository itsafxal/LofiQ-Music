Windows Defender SmartScreen & Portable Unblock Guide

Because LofiQ is an independent open-source release without an enterprise EV certificate, Windows SmartScreen may show an advisory warning on first launch. This is completely expected and safe.

  • Installer (.exe) If Windows Defender shows "Windows protected your PC", click "More info" and then select "Run anyway".
  • Portable (.zip) Before extracting, right-click LofiQ-v1.0.4-Windows-Portable.zip → select Properties → check "Unblock" under the Security section at the bottom → click Apply.
Desktop Architecture

Engineered for PC Audiophiles

Bit-perfect audio playback, hardware acceleration, and seamless system control for Windows 10 and 11.

Native libmpv

WASAPI Bit-Perfect Streaming

Bypasses Windows system mixers via libmpv audio endpoints for clean, jitter-free 320kbps lossy and lossless FLAC reproduction.

ISO Standard

10-Band Graphic Equalizer

Tailor your sound signature with 10 calibrated ISO center frequencies (31Hz to 16kHz), Bass Boost, and Spatial Virtualization.

Zero Overlap

Gapless & Equal-Power Crossfade

True dual-player architecture with early 10s silent preloading for zero-gap live concert albums and smooth crossfade transitions.

System Media

Windows SMTC & Media Keys

Integrated with Windows System Media Transport Controls. Control playback, see artwork on lockscreen, and use keyboard media keys.

Karaoke Engine

Real-Time Synced Lyrics

Word-by-word synchronized scrolling lyrics fetched automatically via LRCLIB & Kugou dual-providers with zero lag.

No Bloat

Lightweight Footprint

Native compiled binary with sub-100MB RAM usage during active streaming. No heavy web wrappers or Electron bloat.
