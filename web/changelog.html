Android & TV Release

v1.0.6 (Build 69) — Gesture Queue & TV Universal

November 14, 2026

v1.0.6 Latest Stable
  • ✦ 🚀 Official Production Release (V1.0.6 - Build 69): Full release assembly and distribution pipeline verification.
  • ✦ ✨ Player Queue Gesture: Removed visible 'Q' button from the player interface. The queue is now revealed via an intuitive swipe-up gesture with smooth Jetpack Compose transitions.
  • ✦ ⬇️ Real-Time Download Notification: Foreground Android notification progress bar displays live download percentage and automatically dismisses upon completion, failure, or cancellation.
  • ✦ 📺 Android TV Universal Compatibility: Added LEANBACK_LAUNCHER intent filter and official 640x360 tv_banner.png for full launcher integration on Android TV, Google TV, and Fire TV.
  • ✦ 🎮 TV Remote Media Keys: Native hardware remote Play/Pause, Next, Previous, Fast-Forward, and Rewind media key responsiveness.
  • ✦ 📋 Smart Queue Management & Home Reset: Universal long-press song context menu (LIFO Play Next, FIFO Add to Queue) across 8 app surfaces, and deterministic Home tab reset.

Windows Desktop Release

v1.0.4 (Build 67) — Audiophile Desktop Engine

November 14, 2026

v1.0.4 Latest Stable
  • ✦ 🚀 Official Windows Desktop Release: Native 64-bit (x64) release built on Flutter and media_kit with native libmpv.
  • ✦ 🛡️ Hardened Inno Setup Packaging: Inno Setup installer script with proper AppUserModelID registration and taskbar identity.
  • ✦ 📦 Standalone Portable ZIP: Added zero-install LofiQ-v1.0.4-Windows-Portable.zip with Mark-of-the-Web (MotW) unblock instructions.

  • ✦ 🎛️ 10-Band Graphic Equalizer: 10-band ISO graphic equalizer with Bass Boost and Virtualizer synchronized across both audio slots.
  • ✦ ⌨️ SMTC Media Controls: Windows System Media Transport Controls, taskbar thumbnails, and keyboard media keys integration.
